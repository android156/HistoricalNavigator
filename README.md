# Исторический Навигатор (Historical Navigator)

Интерактивное веб-приложение для исследования исторической информации по географическим координатам и временным периодам с использованием искусственного интеллекта.

## 🌟 Возможности

- Интерактивная карта с выбором локации
- Поиск мест по названию
- История поисков на карте
- Временная навигация:
  - Год (например: 1255)
  - Период (например: 1274-1311)
  - Дата (например: 23.06.1984)
- Генерация исторических данных через GPT-4
- Визуализация исторических сцен через DALL-E 3
- Определение адреса по координатам
- Логирование действий пользователя
- Кластеризация исторических точек
- Локальное хранение изображений

## 🛠️ Технологии

- **Backend**: Python, Flask, SQLAlchemy
- **Frontend**: JavaScript, Bootstrap, Yandex Maps
- **AI**: OpenAI (GPT-4, DALL-E 3)
- **База данных**: SQLite

## 🔧 Установка

1. Добавьте API ключи в секреты Replit:
   - `YANDEX_MAPS_API_KEY`
   - `OPENAI_API_KEY`
   - `FLASK_SECRET_KEY`

2. Нажмите кнопку Run для запуска проекта

## 📊 API Endpoints

- `GET /`: Главная страница
- `POST /api/historical-data`: Получение исторических данных
- `GET /api/historical-points`: Получение сохранённых точек
- `POST /api/log`: Логирование действий

## 📝 Использование

1. Выберите точку на карте или введите название места
2. Укажите временной период
3. Нажмите "Найти"

Система предоставит:
- Описание территории в выбранный период
- Исторические события
- Информацию о культуре и быте
- Правителей периода
- Визуализацию исторической сцены

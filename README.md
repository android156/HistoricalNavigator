
# Исторический Навигатор (Historical Navigator)

Веб-приложение для исследования исторической информации по географическим координатам и временным периодам. Проект использует Yandex Maps API для навигации и OpenAI GPT-4 для генерации исторических данных.

## 🌟 Основные возможности

- Интерактивная карта с возможностью выбора локации
- Поиск мест по названию
- Сохранение и отображение истории поисков на карте
- Временная навигация с поддержкой различных форматов:
  - Год (например: 1255)
  - Период (например: 1274-1311)
  - Конкретная дата (например: 23.06.1984)
- Генерация исторических данных с помощью ИИ
- Интеграция с музейными API
- Визуализация исторических сцен с помощью DALL-E 3
- Автоматическое определение адреса по координатам
- Логирование действий пользователя
- Кластеризация близких исторических точек на карте

## 🛠️ Технологический стек

- **Backend**: Python, Flask
- **Frontend**: JavaScript, HTML5, Bootstrap
- **База данных**: SQLite (SQLAlchemy ORM)
- **API**: 
  - Yandex Maps API (геокодирование, карты)
  - OpenAI API (GPT-4, DALL-E 3)
  - Музейные API

## 🚀 Запуск проекта

1. Убедитесь, что у вас есть необходимые API ключи:
   - `YANDEX_MAPS_API_KEY`
   - `OPENAI_API_KEY`

2. Добавьте API ключи в секреты Replit (Tools -> Secrets)

3. Запустите приложение через интерфейс Replit или командой:
   ```bash
   python main.py
   ```

## 💡 Использование

1. На главной странице отображается карта и форма поиска
2. Выберите точку на карте или введите название места
3. Укажите временной период в одном из поддерживаемых форматов
4. Нажмите "Найти" для получения исторической информации
5. Результат будет содержать:
   - Описание территории
   - Основные исторические события
   - Локальные события в радиусе 50км
   - Информацию о культуре и быте
   - Правителей периода
   - Музейные артефакты
   - Визуализацию исторической сцены от DALL-E
   - Интерактивные ссылки на Wikipedia

## 📊 API Endpoints

- `GET /`: Главная страница
- `POST /api/historical-data`: Получение исторических данных
- `GET /api/historical-points`: Получение сохранённых исторических точек
- `POST /api/log`: Логирование действий пользователя
